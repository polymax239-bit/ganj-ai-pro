# GANJ AI PRO — نسخه موبایلی آزمایشی

## این نسخه چه می‌کند؟
- دریافت کندل‌های واقعی Binance Spot از API عمومی
- تایم‌فریم مرجع پیش‌بینی 4H
- بررسی روندهای 1H، 4H و 1D
- محاسبه RSI، MACD، EMA، ATR و ADX
- استخراج حمایت و مقاومت از پیوت‌های تاییدشده
- آموزش مدل Random Forest چندافقی برای تخمین بازده 1 تا 10 کندل آینده
- آزمون زمانی ساده (train روی گذشته، test روی بازه بعدی)
- نمایش نمودار، 10 کندل تخمینی، سیگنال ترکیبی و سطوح ریسک

## راه‌اندازی روی گوشی اندروید (بدون نصب Python)
1. فایل ZIP را در GitHub بارگذاری کن و یک repository جدید بساز.
2. وارد https://render.com شو و با GitHub ثبت‌نام کن.
3. در Render گزینه New > Blueprint را انتخاب کن و repository پروژه را وصل کن.
4. Render فایل `render.yaml` را می‌خواند؛ Deploy را بزن.
5. پس از پایان Deploy، آدرس HTTPS سایت را در Chrome گوشی باز کن.
6. از منوی Chrome گزینه Add to Home screen را بزن تا مانند اپ روی صفحه گوشی باشد.

## راه‌اندازی محلی (نیازمند کامپیوتر)
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --reload
```
سپس `http://127.0.0.1:8000` را باز کن.

## نکات مهم و محدودیت‌ها
- این نسخه Spot و جفت‌ارزهای USDT را می‌خواند؛ فیوچرز، فاندینگ‌ریت، اوپن اینترست، دفتر سفارش عمیق و خبرها هنوز در مدل نیستند.
- این برنامه فقط تحلیل می‌کند و سفارش خرید/فروش ارسال نمی‌کند.
- هیچ کلید API، رمز عبور یا کلید برداشت صرافی لازم نیست.
- کندل در حال تشکیل برای آموزش و تحلیل استفاده نمی‌شود؛ پیش‌بینی با بسته‌شدن کندل 4H تغییر می‌کند، اما مدل با درخواست مجدد دوباره آموزش می‌بیند و خروجی ممکن است با ورود داده جدید تغییر کند.
- ده کندل آینده تخمین مدل هستند. OHLC آینده واقعی قابل دانستن نیست؛ دامنه High/Low با ATR تخمین زده می‌شود.
- دقت گزارش‌شده فقط ارزیابی تاریخی ساده است، نه تضمین دقت آینده. پیش از هر استفاده معاملاتی، بک‌تست walk-forward دقیق‌تر، کارمزد، لغزش قیمت و شرایط بازار باید اضافه و بررسی شوند.
- Render رایگان برای آزمایش مناسب است؛ ممکن است سرویس مدتی بدون درخواست بخوابد و اولین بازشدن کند باشد. برای کار مداوم از میزبانی پایدارتر استفاده کن.
