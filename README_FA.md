# GANJ AI PRO

## راه‌اندازی روی Streamlit Community Cloud
1. فایل `app.py` و `requirements.txt` را در ریشه مخزن GitHub قرار دهید.
2. در Streamlit Community Cloud، مخزن و شاخه `main` را انتخاب کنید.
3. Main file path باید `app.py` باشد.
4. Python 3.12 انتخاب شود.

## قابلیت‌ها
- کندل‌های بسته‌شده Binance Spot در 4H، 1D و 1H
- دفتر سفارش عمومی (Depth) و معاملات تجمیعی (AggTrades)
- نسبت فشار خرید/فروش و عدم تعادل دفتر سفارش
- EMA20/50/200، RSI، MACD، ADX، ATR و حجم
- حمایت/مقاومت، ساختار HH/HL و LH/LL، واگرایی RSI و FVG
- فیلتر روند BTC
- 10 کندل پیش‌بینی تخمینی بر اساس مسیرهای تاریخی مشابه

## محدودیت‌ها
این نسخه فقط از داده‌های عمومی Binance Spot استفاده می‌کند. سفارش ثبت نمی‌کند و به حساب شخصی/معاملات خصوصی متصل نیست. داده دفتر سفارش لحظه‌ای و ناپایدار است. پیش‌بینی آماری تضمینی نیست.
